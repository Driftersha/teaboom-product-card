# Teaboom Product Card

Адаптивная карточка товара для интернет-магазина Teaboom, выполненная в рамках тестового задания.

## Demo

Карточка товара поддерживает выбор фасовки с динамическим обновлением артикула и стоимости товара.

## Features

- адаптивная верстка для desktop, tablet и mobile;
- переключение вариантов фасовки;
- динамическое обновление артикула и цены;
- семантическая HTML-разметка;
- доступные состояния элементов управления;
- адаптивные изображения;
- BEM-структура CSS-классов.

## Technologies

- HTML5
- SCSS
- JavaScript (ES6+)
- BEM
- Git

## Project structure

- `index.html` — разметка карточки товара;
- `scss/` — исходные SCSS-стили;
- `css/` — скомпилированные стили;
- `js/main.js` — логика переключения вариантов товара;
- `images/` — изображения проекта;
- `fonts/` — локальные шрифты.

## Run locally

Проект не требует установки зависимостей.

Откройте `index.html` в браузере или запустите проект через Live Server.
